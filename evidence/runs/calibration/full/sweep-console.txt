COST -- and which cost it is
==============================================================================
Every rung relaunches the implementation: R0 once for the whole corpus, R1 once
per trace, R2 once per property-round. A launch is a warm build check plus a
process start plus a health wait, and that price differs by language. So raw
seconds mix what the RUNG costs with what the LANGUAGE costs. Both are below.

  corner   floor/launch of which build  samples           spread
  go            4040 ms         479 ms        3     2663-5619 ms
  rust          4853 ms          89 ms        3     3097-6358 ms

  corner   rung            launches wall killed  wall clean  tool clean
  go       R0 corpus              -       2.4s          -          -
  go       R1 diff-fuzz           -      61.7s          -          -
  go       R2 property           54      60.8s     127.1s   -91.0s *
  rust     R0 corpus              -       0.8s          -          -
  rust     R1 diff-fuzz           -      12.3s          -          -
  rust     R2 property           54      17.4s      31.8s  -230.3s *

  wall killed  mean wall for a mutant this rung caught. NOT comparable with the
               clean column, and not reliably smaller either. R1 stops at its
               first mismatch -- then shrinks, and every shrink attempt is
               another server launch, so at low trace counts a kill can cost
               several times a clean pass. The launch count of a kill depends
               on the defect, so it is not corrected and no tool figure is
               derived from it.
  wall clean   mean wall for a full pass -- the worst case, and what a sweep of
               a correct implementation actually costs.
  tool clean   wall clean minus launches x measured floor. The rung's own cost
               with process startup removed. Reported only where the launch
               count is known from the configuration -- never inferred.
  *            the correction came out at or below zero. Not an error and not
               hidden: it means this rung's own work costs no more than the
               servers it launches, so at this configuration the rung IS process
               startup. Compare rungs by their launch counts, not their seconds.
  Mutant setup (materialise + warm the build cache) is charged to no rung; see
  the setups block in results.json.
